About Formula Finder

Formula Finder is a web application designed to help determine which formula to use, based on given values in your exercises. We have aimed to include the main formulas of physics and physical chemistry, from danish gymnasium level to first year university level.

The Formula Finder can either be used with Symbols or Units. These can be inputted in the text fields as LaTeX math environment symbols, or simply selected from the dropdown menus. The application will then return any formulas that matches the inputted values.

If no good result pops up, it might be because what you are trying to find the result to, does not include all of the inputted values. In that case, try to remove some of the inputted values, and see if a formula pops up.
